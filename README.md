# Update Bot SV

Dashboard web para acompanhamento de **vendas e estoque**, desenvolvido para apoiar a análise operacional de produtos e resultados comerciais.

## Sobre o projeto

O Update Bot SV é uma aplicação front-end construída com HTML, CSS e JavaScript puro. O projeto organiza informações de vendas e inventário em uma interface visual, com recursos para acompanhar indicadores, consultar dados, identificar tendências e exportar informações para análises externas.

## Funcionalidades

- Dashboard para visualização de vendas e estoque.
- Organização dos módulos de vendas e inventário.
- Indicadores e tendências para apoiar a análise dos dados.
- Exportação dos dados de vendas.
- Exportação dos dados de estoque.
- Alternância entre tema claro e escuro.
- Interface responsiva para diferentes tamanhos de tela.
- Execução diretamente no navegador, sem necessidade de servidor backend.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/paulorsclima/update-botsv.git
```

2. Acesse a pasta do projeto:

```bash
cd update-botsv
```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no VS Code para executar o projeto durante o desenvolvimento.

## Objetivo profissional

Este projeto faz parte do portfólio de Paulo Ricardo e demonstra a aplicação de desenvolvimento web para resolver necessidades de gestão e análise no contexto de e-commerce.

A proposta combina desenvolvimento front-end, organização de dados e visão de negócio para facilitar o acompanhamento de operações de vendas e estoque.
